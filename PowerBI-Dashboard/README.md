# Power BI Dashboard Project

## Project Overview
This project demonstrates data visualization and business intelligence reporting using Microsoft Power BI. The report is designed to present data through visualizations that help users explore information and identify useful insights.

## Tools & Technologies
- Microsoft Power BI Desktop
- Data Visualization
- Business Intelligence
- Dashboard Reporting

## Project Files
- `powerbi-demo-1 (1).pbix` — Power BI report file containing the dashboard and report model.

## How to View the Dashboard
1. Download the `.pbix` file from this repository.
2. Open the file using Microsoft Power BI Desktop.
3. Explore the report pages, visualizations, and available filters.

## Key Learning Outcomes
- Creating visual reports in Power BI.
- Presenting data through dashboards.
- Exploring business information using visualizations.
- Developing practical business intelligence skills.
