# Excel Data Analysis Project

## Overview
This project uses Microsoft Excel to organize, analyze, and summarize data for business insights.

## Tools Used
- Microsoft Excel
- Data cleaning and organization
- Spreadsheet formulas and summaries
- Data analysis and reporting

## Project File
- `Book1.xlsx` — Excel workbook containing the project data and analysis.

## How to View
1. Download `Book1.xlsx`.
2. Open it in Microsoft Excel.
3. Explore the worksheets, formulas, summaries, and visualizations.
